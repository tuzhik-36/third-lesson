
# Python API Aggregator

## Описание
Учебный Python-проект для работы с открытыми API.

Программа выполняет:
- Получение предполагаемого возраста по имени (Agify API).
- Получение статистического предположения о поле (Genderize API).
- Получение постов через JSONPlaceholder API.
- Использование HTTP-заголовков и параметров запроса.

## Используемые технологии
- Python 3
- Requests
- REST API
- JSON

## Установка

Склонируйте репозиторий:

```bash
git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Введите имя, когда программа попросит.
