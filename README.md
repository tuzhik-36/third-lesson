# OSINT Aggregator — Educational Project

Учебный проект на Python для изучения работы с HTTP API.

## Возможности

- GET-запросы к Agify и Genderize.
- Получение тестовых публикаций через JSONPlaceholder.
- Формирование JSON-отчёта.
- Отправка данных на тестовый сервер httpbin.
- Скачивание учебного изображения.
- Обработка HTTPError и Timeout.

## Используемые технологии

- Python
- Requests
- REST API
- JSON

## Установка

Клонируйте репозиторий:

```bash
git clone YOUR_REPOSITORY_URL
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите программу:

```bash
python main.py
```

## Примечание

Проект предназначен исключительно для обучения работе с API и тестовыми данными. Оценки Agify и Genderize являются статистическими и не подтверждают сведения о конкретных людях.
